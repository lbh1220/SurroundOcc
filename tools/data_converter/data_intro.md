# AirSim 多传感器数据集结构说明

本数据集用于多无人机、多传感器仿真采集，支持多种传感器类型（如RGB相机、深度相机、IMU、GPS、LiDAR等），并支持多任务轨迹采集。

## 目录结构

```
/dataset_root/
├── Drone1/
│   ├── 1700000000/                # 每个任务/轨迹一个子文件夹，文件夹名为任务起始时间戳
│   │   ├── CAM_FRONT/             # 每个需要保存的传感器一个子文件夹，名称与配置一致
│   │   │   ├── 123.456.png        # 按时间戳命名的图片（RGB或Depth）
│   │   │   └── ...
│   │   ├── CAM_FRONT_DEPTH/
│   │   │   ├── 123.456.png
│   │   │   └── ...
│   │   ├── ...                    # 其他传感器
│   │   ├── data.csv               # 该任务的状态数据（见下文）
│   │   └── mission_info.json      # 任务信息
│   └── ...                        # 其他任务
├── Drone2/
│   └── ...
└── ...                            # 其他无人机
```

- `Drone1/`、`Drone2/`：每个无人机一个文件夹
- `1700000000/`：每个任务/轨迹一个子文件夹，文件夹名为任务起始时间戳
- `CAM_FRONT/`、`CAM_FRONT_DEPTH/`等：每个需要保存的传感器一个子文件夹，名称与配置一致
- `data.csv`：每个任务的状态数据
- `mission_info.json`：任务的详细信息

## data.csv 字段说明

data.csv为每个任务采集的时序状态数据，字段如下：

| 字段名         | 含义                         |
| -------------- | ---------------------------- |
| timestamp      | 时间戳（秒，浮点数）         |
| desired_vel    | 期望速度（任务参数）         |
| quat_1~quat_4  | 四元数姿态（x, y, z, w）     |
| pos_x~pos_z    | 位置（x, y, z，单位：米）    |
| vel_x~vel_z    | 速度（body系，单位：米/秒）  |
| velcmd_x~velcmd_z | 期望速度（body系，单位：米/秒）|
| is_collide     | 是否碰撞（True/False）       |

> 说明：
> - 位置、姿态、速度等均为NED系（北东地）或ENU系（东北天），具体以配置和代码为准。
> - 期望速度、实际速度均为body系（机体坐标系），已做旋转变换。
> - 其他传感器（如IMU、LiDAR等）数据可根据需要扩展存储。

## mission_info.json 说明

每个任务文件夹下的`mission_info.json`记录了该任务的详细参数，包括起止点、速度、起止时间等。

---

如需扩展其他传感器或自定义数据结构，请参考`data_collector_node.py`和配置文件进行修改。
